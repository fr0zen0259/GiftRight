## 二、五大核心改进点深度解析

### 1. 推荐理由（why_recommended）全面去 AI 化

#### 【问题根因】
大语言模型在没有严苛负向约束时，极易陷入通用营销模版：
- 机械复读已选条件（例如：“这款礼物价格落在你的 100-200 元预算内……”）；
- 滥用空洞四字成语（“兼具实用与美观”、“正合送礼分寸”、“适合想加点心意又不想太隆重的关系”）。

#### 【解决措施】
1. **在 `LLM 2` 节点中树立严苛红线**：
   - 严禁出现“价格在预算内/落在预算内/符合预算/价格合适/预算也压在XX内/价格轻松”等任何价格或预算字样；
   - 严禁每条都以“XX生日想送实用的…”、“送XX不会出错…”等模板句开篇；
   - 规定直接以【功能/材质 + 真实使用场景 + 解决什么体验】切入。
2. **前后端双重代码过滤防线**：
   - **后端（`app.py`）**：在数据下发前，通过多阶段正则表达式与关键词黑名单，自动剪除偶发的违规价格套话；
   - **前端（`app.js`）**：在卡片挂载 DOM 前执行 `cleanAiCopy` 校验，确保到达用户眼前的文案 100% 纯净。

---

### 2. 随礼贺卡寄语（card_message）真诚重塑

#### 【问题根因】
- **文风悬浮**：模型倾向于输出微信朋友圈式的假大空鸡汤文，不仅假，而且根本无法抄写在现实中的实体贺卡上。
- **架构冲突**：早期 USER 提示词写着“请在 JSON 对象上增加 card_message 并原样返回整个 JSON”，导致大模型在输出大括号时经常由于长度超限或字段遗失而报错。

#### 【解决措施】
1. **文风接地气**：
   - 严禁“愿岁月温柔以待”、“深情厚谊”、“历久弥新”、“岁月静好”、“如期而至”等空洞大词；
   - 限制 50 个中文字符以内，模拟真实手写便签纸的自然口吻（如送朋友：“生日快乐！忙归忙，平时记得多喝水、多歇歇。”）；
   - 探病、慰问场合严禁庆祝语气，DIY 模式只能表达“亲手准备了这份小方案”，不夸大。
2. **架构彻底解耦**：
   - `Card Writer` 节点只负责输出一句纯文本字符串；
   - 由后置的 `Output Assembler` 代码节点负责将该字符串安全拼装入最终 JSON 根对象，架构稳定且执行迅速。

---

### 3. AI 推荐候选数量对齐契约（5 ➔ 8 件）

#### 【问题根因】
- 在 `LLM 2` 的历史提示词中，第 1 条和第 3 条误保留了早期测试阶段的“优先选出 5 个”和“候选不足 5 个时不要补造”，导致界面长期缺失 3 张卡片。

#### 【解决措施】
- 全量修改为“优先选出 8 个（eligible_products 不足 8 个时有多少选多少）”和“候选不足 8 个时不要补造”；
- 配合前端 Grid 布局，使推荐区域呈现出丰满饱满的 8 张精选推荐卡片（涵盖 safe、heart、special）。

---

### 4. Dify 工作流与万字高容错代码体系

#### 【问题根因】
- 大模型生成长 JSON 时，经常会在数组或对象最后一个元素后面多打一个英文逗号（`trailing comma`），标准的 `json.loads` 会直接抛出 `JSONDecodeError` 异常，导致请求降级走本地硬规则。

#### 【解决措施】
1. **节点「代码执行 2」搭载 10,038 字符增强解析脚本**：
   - 自动识别并修剪尾部逗号（`re.sub(r',\s*([\]}])', r'\1', text)`）；
   - 自动剥离 `<think>...</think>` 思维链标签；
   - 智能截取首个 `{` / `[` 至末尾 `}` / `]`，防止 Markdown 符号污染；
   - 严格保留 DIY 手作属性字段（制作天数、材料、步骤、保存方法、过敏原等），避免被校验器过滤。
2. **拓扑连线优化**：
   - 知识库检索结果统一流经「排序上下文整理」节点压缩后输入排序模型，删除了直插模型的 3 根冗余连线，降低 Token 消耗并缩短响应时延 1~2 秒。

---

### 5. 商品库资质澄清与价格口径规范

#### 【数据事实】
系统内嵌的真实商品数据库（`products_taobao_authorized_v3.json`，共 4,180 件）来源分布：
- **淘宝 / 天猫在售商品**：**3,148 件**（占比 75.3%）
- **天猫超市 / 官方旗舰店公开检索精选**：**1,032 件**（占比 24.7%）
- **1688 货源**：仅极少量企业年会金砖、批量伴手礼等特殊定制品（数十件）。

#### 【口径声明】
提示词末尾的“价格口径说明”系防御性说明，避免大模型把极个别的批发单价误认为是普通零售价。用户通过系统挑选到的礼物，绝大部分均为天猫、淘宝主流品牌正品。
